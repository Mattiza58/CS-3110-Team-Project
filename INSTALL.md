
# Installation Guide

From the `team-project` directory, run:

```bash
opam install . --deps-only --with-test
```

This should install all the dependencies needed for the project. `elm_playground` is a major library that is needed for this project. A list of the dependencies can be found in `dune-project`, and otherwise reference `ELM_GUIDE.md` for the playground installation.

To run the game, please reference `WEB_SERVER.md`
