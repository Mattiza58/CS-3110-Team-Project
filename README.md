## Project Overview (WIP)
This repository contains our final team project for Cornell University's CS 3110: Data Structures and Functional Programming. Our game, Caml League, is a two-player soccer game where players try to score as many goals as they can within a set time frame. Both players can play on the same device. Player 1 controls with WASD, while Player 2 uses the arrow keys. Our project is developed in OCaml using `js_of_ocaml` for the web page and the `elm_playground` library for graphics. The game is currently a work in progress.

## Running the Game
The game can currently be hosted locally in the browser. In the `team-project` folder run:
```bash
dune build public/index.html server/main.exe
_build/default/server/main.exe _build/default/public
```

Then open http://127.0.0.1:8080 in your browser!
